---

## 1. Назначение

**Code Block Generator** — расширение для Visual Studio Code, которое генерирует готовые блоки кода (`if`, `for`, `while`, `switch`, `try/catch`) на основе параметров, введённых пользователем. Плагин автоматически определяет язык текущего файла (JavaScript/TypeScript, Python, Java), подставляет корректные отступы и вставляет сгенерированный код в позицию курсора.

### Ключевые возможности

- Выбор типа блока через `QuickPick`.
- Ввод параметров через `InputBox` с валидацией (не пусто, целое число).
- Поддержка трёх языков: JavaScript (включая TypeScript), Python, Java.
- Автоматическое определение языка по `languageId` документа.
- Учёт текущего отступа строки, на которой стоит курсор.
- Вставка кода в позицию курсора без перезаписи содержимого.

### Ограничения

- Работает только в активном редакторе (не в терминале и не в панелях).
- Не поддерживает языки, отличные от JS/TS, Python, Java.
- Не выполняет рефакторинг существующего кода — только вставку нового.
